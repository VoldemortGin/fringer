The Fringer Bar holds what you hide.

A second bar drops down with every hidden icon, captured live. Click any one and it behaves exactly like the original. Nothing is faked, nothing is lost.

Three states per icon

Shown, hidden, or tucked away until you search. Drag any icon between them and the order sticks across restarts.

Find any item, fast

One hotkey opens search. Type a few letters, press return, and the item fires.

Hotkeys for anything

Assign a global shortcut to any menu bar item, or to the Fringer Bar itself. Hands stay on the keyboard.

Presets for every mode

Save a layout for meetings, focus, or recording. Each preset remembers which icons show, which hide, and how they are arranged. Switch by hand whenever the moment changes.

Triggers that switch for you

Let a preset activate on its own: on battery, on a given Wi-Fi network, at a set time, or when a particular app comes to the front. Set it once and forget the menu bar exists.
